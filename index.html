Import Custom Catalog

Import catalog objects from a CSV file. You'll get a preview showing any duplicates so you can decide how to handle each row.

CSV Format
  • First row must be the column headers (any order): id,name,type,constellation,ra,dec,mag,sizeX,sizeY,filters,otherNames,description
  • id, name, ra, dec are required
  • RA is in decimal hours (0–24), Dec is in decimal degrees (-90 to +90)
  • filters uses pipe | to separate values: Ha|OIII|SHO
  • Works with standard Excel and Google Sheets exports (Save As → CSV)
